# บัญชีแหล่งอ้างอิง (cleanroom-webapp)

วันที่ตรวจแหล่งและเข้าถึงทุกรายการ: **2026-11-10** (10 พฤศจิกายน 2569)

ระดับสถานะ:
- **ยืนยันแล้ว** = เปิดอ่านต้นฉบับหรือภาพสแกนต้นฉบับแล้ว ใช้เป็นเกณฑ์ได้
- **บางส่วน** = คำแปลไม่เป็นทางการ หรืออ่านผ่านเครื่องมือสรุป ใช้ได้แต่ต้องบอกผู้ใช้ว่าความมั่นใจต่ำกว่า
- **ยืนยันไม่ได้** = เปิดไม่ได้หรือไม่พบ **ห้ามใช้เป็นเกณฑ์**

หมายเหตุ: เว็บราชกิจจานุเบกษาเปิดโดยตรงไม่ได้ในวันที่ตรวจ จึงใช้ภาพสแกนราชกิจจานุเบกษาที่หน่วยงานรัฐหรือคลังสื่อสาธารณะเก็บไว้ ผู้ใช้ควรเทียบกับราชกิจจานุเบกษาเมื่อใช้งานจริง

## ข้อความสำคัญจากแหล่ง (สรุปด้วยคำของผู้เขียนสกิล)

- **S-01 ม.6 วรรคสอง**: ลิขสิทธิ์ไม่คลุมถึงความคิด ขั้นตอน กรรมวิธี ระบบ วิธีใช้หรือทำงาน แนวความคิด หลักการ การค้นพบ หรือทฤษฎี → "ฟีเจอร์" และ "วิธีทำงาน" ของแอปไม่ได้รับความคุ้มครองลิขสิทธิ์ แต่ "โค้ด ข้อความ ภาพ" ที่แสดงออกได้รับความคุ้มครอง
- **S-01 ม.4 "ทำซ้ำ"/"ดัดแปลง"**: สำหรับโปรแกรม หมายถึงคัดลอก หรือเปลี่ยนรูป แก้ไข ในส่วนอันเป็นสาระสำคัญ "โดยไม่มีลักษณะเป็นการจัดทำงานขึ้นใหม่" → การเขียนใหม่ทั้งหมดด้วยตัวเองต่างจากการคัดลอกแล้วแก้
- **S-01 ม.30**: ทำซ้ำ ดัดแปลง เผยแพร่ หรือให้เช่าโปรแกรมโดยไม่ได้รับอนุญาต = ละเมิด
- **S-01 ม.35**: ข้อยกเว้นสำหรับโปรแกรม (เช่น วิจัยหรือศึกษา) ใช้ได้เฉพาะเมื่อ "ไม่มีวัตถุประสงค์เพื่อหากำไร" และไม่ขัด ม.32 วรรคหนึ่ง → งานเชิงพาณิชย์พึ่ง ม.35 ไม่ได้
- **S-05 ม.53/4, 53/6, 70/1**: การทำให้มาตรการควบคุมการเข้าถึงไม่เกิดผล หรือทำ/แจกเครื่องมือเพื่อการนั้น เป็นการละเมิด โทษตาม ม.70/1 คือปรับไม่เกิน 100,000 บาท; ถ้าเพื่อการค้า จำคุกไม่เกิน 2 ปี หรือปรับไม่เกิน 400,000 บาท หรือทั้งจำทั้งปรับ
- **S-06 ม.109, 46 วรรคสอง**: เลียนเครื่องหมายที่จดทะเบียนให้คนหลงเชื่อ มีโทษอาญา; แม้ไม่ได้จดทะเบียน ก็ยังฟ้องฐานลวงขายได้ → ห้ามใช้ชื่อ/โลโก้ที่คล้ายจนสับสน
- **S-08**: หน้าจอ (screen displays) ถือเป็นส่วนของงานโปรแกรม และเกมมีงานภาพเสียงแยกได้ → ห้ามคัดลอกภาพหน้าจอ กราฟิก หรือทรัพยากรของเกมต้นแบบ
