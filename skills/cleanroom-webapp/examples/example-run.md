# ตัวอย่างการใช้สกิล: แอปจดโน้ตแบบการ์ด

> ตัวอย่างนี้ใช้ **ต้นแบบสมมติ** ชื่อ "แอปต้นแบบ A" แทนแอปจดโน้ตแบบการ์ดที่มีอยู่ทั่วไป ไม่ได้อ้างถึงสินค้าของยี่ห้อใด
> แสดงผลแต่ละเฟสแบบย่อ ไม่มีโค้ดเต็ม

---

## เฟส 0 — คัดกรอง

**ผู้ใช้:** อยากได้แอปจดโน้ตแบบการ์ดเหมือนแอปต้นแบบ A ที่ใช้อยู่ แต่อยากมีของตัวเอง ใช้คนเดียว อาจแจกเพื่อนฟรี อยากให้ดึงโน้ตเก่าจากแอป A มาด้วย และขอใช้โลโก้รูปการ์ดสีเหลืองแบบเดียวกัน

**สกิลถาม (เฉพาะที่ขาด):**
1. ฟีเจอร์หลักที่ต้องการคืออะไร
2. ต้องเปิดใช้ทั้งคอมและมือถือ โดยข้อมูลตรงกันไหม

**ผู้ใช้:** สร้างการ์ด ใส่สี ติดป้าย ค้นหา จัดเป็นคอลัมน์ลากได้ ใช้แค่ในคอมเครื่องเดียวก่อน

**สกิลปรับขอบเขต:**
- การดึงโน้ตโดยให้สกิลล็อกอินบัญชีแอป A แทนผู้ใช้ไม่ทำ — แนวปฏิบัติ: สกิลไม่รับรหัสผ่านของผู้ใช้และไม่ล็อกอินแทน และการดึงข้อมูลอัตโนมัติอาจขัดข้อกำหนดการใช้งานของแอป A (U-07) (ถ้าเป็นการข้ามหรือหลบการล็อกอิน จึงจะเข้า ม.53/4 [S-05] ซึ่งกรณีนี้ไม่ใช่) → เสนอแทน: ผู้ใช้กดปุ่มส่งออกไฟล์ของแอป A เอง (เช่น CSV/JSON) หรือใช้ API ทางการที่ผู้ใช้อนุญาตเอง แล้วแอปเรามีตัวนำเข้าไฟล์นั้น
- โลโก้แบบเดียวกันใช้ไม่ได้ (ศิลปกรรม ม.4, ม.27 [S-01]; เลียนเครื่องหมายให้สับสน ม.109 [S-06 คำแปล]) → จะออกแบบไอคอนใหม่ในเฟส 3

**สรุปขอบเขต:**
ต้นแบบ (อ้างถึงเท่านั้น): แอปต้นแบบ A / ทำ: การ์ด สี ป้าย ค้นหา คอลัมน์ลากวาง นำเข้า-ส่งออกไฟล์ / ไม่ทำ: ซิงก์ เข้าระบบแอป A ใช้โลโก้เขา / ผู้ใช้: ตัวเอง + แจกเพื่อนฟรี / ไม่หากำไร

- แหล่งที่ใช้ศึกษา: การใช้งานจริงที่ผู้ใช้เล่า + หน้าคู่มือทางการของแอป A (ศึกษาแบบ black-box ไม่ดูซอร์ส)
- ต้นแบบไม่ใช่โอเพนซอร์ส → ไม่มีทาง fork ใช้ทางเขียนใหม่

สิ่งที่ **ไม่ได้** ใส่ในสเปก: ภาพหน้าจอของแอป A, ข้อความปุ่มของแอป A, ชื่อฟีเจอร์เฉพาะที่แอป A ตั้ง

## เฟส 6 — ส่งมอบ: README ส่วนแรงบันดาลใจ (ย่อ)

> **แรงบันดาลใจและความแตกต่าง**
> กองการ์ดได้แรงบันดาลใจจากแนวคิดการจดโน้ตเป็นการ์ดของแอปต้นแบบ A ชื่อ "แอปต้นแบบ A" ใช้เพื่ออ้างถึงเท่านั้นและเป็นเครื่องหมายของเจ้าของ
> โครงการนี้ไม่มีส่วนเกี่ยวข้องและไม่ได้รับการรับรองจากเจ้าของแอปต้นแบบ A โค้ด ข้อความ ไอคอน และการออกแบบสร้างขึ้นใหม่ทั้งหมด
> ต่างกันที่: ทำงานในเบราว์เซอร์ ไม่ต้องติดตั้ง ข้อมูลอยู่ในเครื่อง จัดการ์ดเป็นคอลัมน์ ไม่มีการซิงก์
