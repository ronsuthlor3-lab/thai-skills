# ตัวอย่างที่ 3: คำสั่ง (ข้อ 16, แบบที่ 4)

> **หน่วยงานและบุคคลในตัวอย่างนี้เป็นสมมติทั้งหมด** ("กรมสมมติ" ไม่มีอยู่จริง) เลขที่คำสั่ง ฐานอำนาจทางกฎหมาย และลายมือชื่อเว้นเป็น `{…}`

## คำขอของผู้ใช้ (สมมติ)

> ร่างคำสั่งกรมสมมติ แต่งตั้งคณะทำงานพัฒนาเว็บไซต์ของกรม 4 คน ประธาน นายทดสอบ ระบบดี, กรรมการ นางตัวอย่าง มีสุข, กรรมการ นายสมมติ ขยัน, กรรมการและเลขานุการ นางสาวลองดู ตั้งใจ หน้าที่: วางแผน ออกแบบ และดูแลเนื้อหาเว็บไซต์ มีผลตั้งแต่วันที่ลงนาม ผู้ลงนามคืออธิบดีกรมสมมติ

## การตัดสินใจของสกิล

| ประเด็น | เลือก | เหตุผล/อ้างอิง |
|---|---|---|
| ชนิดหนังสือ | คำสั่ง | หนังสือสั่งการ (ข้อ 15, 16) |
| เลขที่คำสั่ง | `{เลขที่}/๒๕๖๙` | เลขเริ่มที่ ๑ เรียงจนสิ้นปีปฏิทิน ทับเลขปี พ.ศ. (ข้อ 16) — ผู้ใช้ต้องเติมเลขจริง |
| อำนาจ | `{…}` | ผู้ใช้ไม่ได้ระบุฐานอำนาจ ห้ามเดาชื่อกฎหมาย (ข้อ 16 "อำนาจ (ถ้ามี)") — ถามผู้ใช้ |
| วันใช้บังคับ | ตั้งแต่บัดนี้เป็นต้นไป | ผู้ใช้ระบุว่ามีผลตั้งแต่วันที่ลงนาม (ข้อ 16) |
| คำขึ้นต้น/ลงท้าย | ไม่มี | คำสั่งไม่มีส่วนประกอบนี้ (ข้อ 16) |

## ร่าง

```
                              [ครุฑ สูง ๓ ซม.]
                            คำสั่งกรมสมมติ
                          ที่ {เลขที่}/๒๕๖๙
              เรื่อง  แต่งตั้งคณะทำงานพัฒนาเว็บไซต์กรมสมมติ
                    ----------------------------------

          เพื่อให้การพัฒนาและดูแลเว็บไซต์ของกรมสมมติเป็นไปอย่างต่อเนื่อง
และมีประสิทธิภาพ อาศัยอำนาจตาม {ระบุบทบัญญัติที่ให้อำนาจ} จึงแต่งตั้ง
คณะทำงานพัฒนาเว็บไซต์กรมสมมติ ดังนี้

          ๑. นายทดสอบ ระบบดี                ประธานคณะทำงาน
          ๒. นางตัวอย่าง มีสุข                 คณะทำงาน
          ๓. นายสมมติ ขยัน                   คณะทำงาน
          ๔. นางสาวลองดู ตั้งใจ                คณะทำงานและเลขานุการ

          ให้คณะทำงานมีหน้าที่ ดังนี้
          ๑. วางแผนการพัฒนาเว็บไซต์ของกรม
          ๒. ออกแบบโครงสร้างและรูปแบบเว็บไซต์
          ๓. ดูแลและปรับปรุงเนื้อหาเว็บไซต์ให้เป็นปัจจุบัน

          ทั้งนี้ ตั้งแต่บัดนี้เป็นต้นไป

                    สั่ง ณ วันที่ {วัน} {ชื่อเดือนเต็ม} พ.ศ. ๒๕๖๙

                              {ลายมือชื่อ}
                              ({คำนำนาม}{ชื่อเต็มผู้ลงนาม})
                            อธิบดีกรมสมมติ
```

## หมายเหตุประกอบร่าง

- ครบองค์ประกอบข้อ 16: คำสั่ง (ชื่อส่วนราชการ) / ที่ / เรื่อง / ข้อความ (เหตุ + อำนาจ + ข้อความที่สั่ง + วันใช้บังคับ) / สั่ง ณ วันที่ / ลงชื่อ / ตำแหน่ง
- ผู้ใช้ไม่ได้ให้ชื่อผู้ลงนาม จึงเว้น `{คำนำนาม}{ชื่อเต็มผู้ลงนาม}` ไว้ (กฎเหล็กข้อ 3)
- ชื่อคณะทำงานใช้ตามที่ผู้ใช้ให้มา (เป็นชื่อสมมติในตัวอย่างนี้)
- "ทั้งนี้ ตั้งแต่…" และ "สั่ง ณ วันที่ … พ.ศ. …" พิมพ์อยู่ในแบบที่ 4 ท้ายระเบียบ (ข้อ 16 ให้ทำตามแบบที่ 4) จึงเป็นส่วนของแบบตามระเบียบ [S-01 หน้า 36] ส่วนคำว่า "บัดนี้เป็นต้นไป" ที่เติมต่อ และวลี "อาศัยอำนาจตาม" ไม่มีในแบบ เป็นแนวปฏิบัติทั่วไป ไม่มีข้อบังคับรองรับ
- คำนำนามหน้าชื่อเต็ม (นาย นาง นางสาว ยศ ฯลฯ) ตามภาคผนวก 3 ข้อ 3
- กระดาษตราครุฑ A4 ครุฑสูง ๓ ซม. กึ่งกลางส่วนบน (ข้อ 75 — ข้อบังคับ)
- ถ้ามีกฎหมายกำหนดแบบคำสั่งไว้โดยเฉพาะ ให้ใช้แบบนั้น (ข้อ 15)
- ตรวจแหล่งเมื่อ 2026-11-10
