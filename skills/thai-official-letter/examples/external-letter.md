# ตัวอย่างที่ 1: หนังสือภายนอก (ข้อ 11, แบบที่ 1)

> **หน่วยงานและบุคคลในตัวอย่างนี้เป็นสมมติทั้งหมด** ("กรมสมมติ", "สำนักงานส่งเสริมการอ่านจังหวัดสมมติ", "โรงเรียนบ้านตัวอย่าง" ไม่มีอยู่จริง) เลขที่หนังสือ เบอร์โทร และลายมือชื่อเว้นเป็น `{…}` ตามกฎเหล็กข้อ 3 ของสกิล

## คำขอของผู้ใช้ (สมมติ)

> ช่วยร่างหนังสือจากสำนักงานส่งเสริมการอ่านจังหวัดสมมติ ถึงผู้อำนวยการโรงเรียนบ้านตัวอย่าง ขอเชิญส่งนักเรียนเข้าร่วมกิจกรรมยอดนักอ่าน วันที่ 15 ธันวาคม 2569 ผู้ลงนามคือผู้อำนวยการสำนักงาน นายสมมติ ใจดี แนบกำหนดการไปด้วย

## การตัดสินใจของสกิล

| ประเด็น | เลือก | เหตุผล/อ้างอิง |
|---|---|---|
| ชนิดหนังสือ | หนังสือภายนอก | ผู้รับเป็นหน่วยงานอื่น (ข้อ 10, 11) |
| คำขึ้นต้น / คำลงท้าย | เรียน / ขอแสดงความนับถือ | ผู้อำนวยการโรงเรียนไม่อยู่ในรายชื่อ 15 ตำแหน่งตามข้อ 3.1 จึงใช้ข้อ 3.2 (ภาคผนวก 2) |
| อ้างถึง | ไม่มี | ไม่มีหนังสือเดิมที่ผู้รับได้รับ (ข้อ 11.6) |
| สิ่งที่ส่งมาด้วย | กำหนดการ ๑ ฉบับ | ข้อ 11.7 |
| ชั้นความเร็ว | ไม่ใส่ | ผู้ใช้ไม่ได้ระบุ (ข้อ 28) |
| ตัวเลข | เลขไทย | แนวปฏิบัติ ไม่ใช่ข้อบังคับในระเบียบ (S-10 บางส่วน) |

## หมายเหตุประกอบร่าง

- ส่วนประกอบเรียงตามข้อ 11.1–11.13 (ไม่มี 11.6 อ้างถึง และ 11.14 สำเนาส่ง เพราะไม่ใช้)
- ส่วนราชการเจ้าของเรื่อง: ผู้ออกเป็นระดับต่ำกว่ากระทรวง จึงลงเพียงกองหรือหน่วยงานที่รับผิดชอบ (ข้อ 11.12) ผู้ใช้ต้องเติมชื่อหน่วยงานจริง
- โครง ๓ ภาค (ภาคเหตุ → ภาคความประสงค์ → ภาคสรุป ตามคำเรียกใน นร 0106/ว 2019 [S-08]) เป็นแนวปฏิบัติ ไม่ใช่ข้อบังคับในระเบียบ ส่วนวลี "ด้วย…", "ในการนี้…", "จึงเรียนมาเพื่อโปรดพิจารณา" เป็นแนวปฏิบัติทั่วไป ไม่มีข้อบังคับรองรับ
- การจัดหน้า (TH Sarabun PSK 16 พอยท์ ขอบซ้าย ๓ ซม. ขวา ๒ ซม. ย่อหน้า ๒.๕ ซม.) ตาม นร 0106/ว 2019 เป็นแนวปฏิบัติ ไม่ใช่ข้อบังคับในระเบียบ
- ตรวจแหล่งเมื่อ 2026-11-10
