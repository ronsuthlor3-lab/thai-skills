# บัญชีแหล่งอ้างอิง (thai-official-letter)

วันที่ตรวจแหล่งและเข้าถึงทุกรายการ: **2026-11-10** (10 พฤศจิกายน 2569)

ระดับสถานะ:
- **ยืนยันแล้ว** = เปิดอ่านต้นฉบับ (หรือภาพสแกนต้นฉบับ) แล้ว ใช้เป็นกฎได้
- **บางส่วน** = เห็นผ่านแหล่งรองหรือเอกสารที่อ้างถึง ใช้ได้แต่ต้องบอกระดับความมั่นใจ
- **ยืนยันไม่ได้** = เปิดต้นฉบับไม่ได้ ห้ามใช้เป็นกฎ

หมายเหตุ: เว็บราชกิจจานุเบกษา (ratchakitcha.soc.go.th) และ soc.go.th มีด่าน Cloudflare ผู้ตรวจเข้าโดยตรงไม่ได้ ฉบับแก้ไขที่ 2–4 จึงใช้สำเนาภาพราชกิจจานุเบกษาที่หน่วยงานรัฐหรือมหาวิทยาลัยรัฐเผยแพร่ ผู้ใช้ควรเทียบกับราชกิจจานุเบกษาอีกครั้งเมื่อใช้งานจริง
